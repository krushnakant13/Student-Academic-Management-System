# Problem Analysis

## Problem Statement

Educational institutions need a simple way to store, organize, update and retrieve student academic information. The system should manage personal information, academic subjects, marks, attendance and club information.

## Inputs

- Roll number
- Registration number
- Student name
- Department
- Date of birth
- Contact information
- Subject names
- Marks
- Attendance
- Clubs

## Outputs

- Student profile
- Search results
- Updated/deleted records
- Average marks
- Grade
- Highest scorer
- Department-wise student list
- Attendance warning report
- Department statistics

## Data Relationships

A student has one profile. A profile contains multiple subjects, marks and attendance values. Each subject corresponds to one marks value and one attendance value.

## Main Operations

1. Add student
2. Search student
3. Update student
4. Delete student
5. Display all students
6. Calculate academic performance
7. Generate department report
8. Generate attendance report
