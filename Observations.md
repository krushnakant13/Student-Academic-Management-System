# Observations

1. Lists are useful for ordered collections such as subjects, marks and attendance.
2. Dictionaries are useful for representing a complete student profile using key-value pairs.
3. Sets are useful when duplicate values should be removed, such as club names or department names.
4. Strings are used for textual information.
5. Functions divide the application into manageable operations.
6. Input validation prevents invalid academic values.
7. JSON file handling allows records to remain available after the program is closed.
8. The integrated system demonstrates how multiple Python collections can work together in a real-world application.
