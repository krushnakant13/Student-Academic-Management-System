# Algorithm Design

## Add Student

1. Start.
2. Ask for roll number.
3. Check whether the roll number already exists.
4. If it exists, display a duplicate-record message.
5. Otherwise collect personal and academic information.
6. Validate marks and attendance between 0 and 100.
7. Store subjects, marks and attendance in lists.
8. Store clubs as a set.
9. Store the complete profile in a dictionary.
10. Add the dictionary to the student list.
11. Save records.
12. Stop.

## Search Student

1. Ask for roll number.
2. Traverse the student list.
3. Compare each student's roll number.
4. Display the matching profile.
5. If no match exists, display "Student not found."

## Update Student

1. Ask for roll number.
2. Find the matching student.
3. Ask for new values.
4. Keep old values when the input is blank.
5. Update the dictionary.
6. Save records.

## Delete Student

1. Ask for roll number.
2. Find the student.
3. Display the record.
4. Ask for confirmation.
5. Remove the record if confirmed.
6. Save records.

## Highest Scorer

1. Calculate the average marks of every student.
2. Compare averages.
3. Select the student with the maximum average.
4. Display the student's details.
